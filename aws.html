Core Patterns I Work With

AWS RAM — Cross-Account Resource Sharing

Sharing subnets, Transit Gateway attachments, and other resources across accounts without duplicating infrastructure — central to keeping a multi-account landing zone lean.

OIDC Federated Authentication

Keyless, short-lived credential exchange for CI/CD pipelines using OpenID Connect — no long-lived IAM access keys stored in pipeline secrets.

IAM / STS Role Chaining

Cross-account role assumption patterns (AssumeRole chains) for least-privilege access across a multi-account organization.

Direct Connect — Hybrid Interconnects

Linking on-prem data centers to AWS VPCs via Direct Connect, paired with VPN failover for resilient hybrid connectivity.
